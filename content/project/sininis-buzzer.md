> ### **Project Background**

The **Sininis Buzzer** project was initiated to bridge the gap between businesses/individuals needing digital marketing amplification and a diverse pool of buzzers and influencers. The primary goal was to create a centralized, user-friendly marketplace where users can easily discover, recruit, and manage marketing services, streamlining the entire process from search to project completion. This platform aims to democratize access to influencer marketing, making it efficient for both service seekers and providers.

---

> ### **Key Features**

As a **Frontend Developer** on this project, I focused on building an intuitive and engaging user experience, implementing key features such as:

- **Service Search & Discovery:** Robust search functionality allowing users to find marketing buzzer and influencer services based on various criteria.

- **Detailed Service Pages:** Comprehensive pages showcasing individual service offerings, including descriptions, budgets, and provider information.

- **Direct Communication:** Integrated chat functionality for seamless communication and negotiation between users and service providers.

- **Recruitment & Service Purchase Workflow:** A streamlined process for users to recruit/purchase desired marketing services.

- **Purchase Progress Tracking:** A dedicated section (like "Penawaran" with "Menunggu" and "Diterima" tabs) to monitor the status and progress of ongoing service procurements.

- **Favorite Services:** Ability for users to bookmark and manage their preferred marketing services.

- **Interactive User Dashboard:** A personalized dashboard providing an overview of activities, coin balance, and quick access to essential features.

- **Coin-based Payment System:** A virtual currency system (e.g., "KOIN EMAS") for transactions within the platform, including top-up functionality.

---

> ### **Tech Stack**

My role as a **Frontend Developer** involved bringing this interactive platform to life using a modern and responsive tech stack:

- **Frontend:**

    - **Vue.js:** Utilized for building a dynamic, component-based, and highly interactive user interface, providing a smooth navigation experience.

    - **Tailwind CSS:** Employed for rapid, utility-first styling, ensuring a clean, consistent, and fully responsive design across various devices.

    - **Vuetify:** Integrated to provide a rich set of pre-built Material Design UI components, accelerating UI development while maintaining a polished and professional aesthetic.

- **Backend:**

    - **Express.js:** The flexible Node.js framework was used to build robust and scalable API endpoints, handling business logic and data processing.

- **Database:**

    - **MySQL:** Chosen as the relational database management system for its reliability and efficiency in storing and managing all application data, including user profiles, job listings, and transactions.

---

> ### **Lessons Learned & Growth**

This project was a significant learning experience, allowing me to deepen my expertise in several key areas:

- **Building Marketplaces:** Gained practical experience in designing and implementing frontend components for a two-sided marketplace, handling distinct user journeys (service seeker vs. provider).

- **Complex UI/UX Flows:** Navigating the intricacies of recruitment, bidding, and progress tracking UIs, ensuring a user-friendly and efficient workflow.

- **API Integration with Express.js:** Enhanced my skills in integrating Vue.js with Express.js APIs, focusing on efficient data fetching, state management, and error handling.

- **State Management in Vue.js:** Applied best practices for state management, crucial for handling complex user interactions and data updates across the application.
