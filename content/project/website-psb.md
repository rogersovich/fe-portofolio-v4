> ### **Project Background**

The "Website PSB" was developed as the official landing page and information hub for a football club based in Bogor. The core problem it solves is providing a centralized, accessible platform for fans and stakeholders to stay updated on the club's activities, match results, team information, and news. Its main objective is to foster community engagement, enhance transparency, and offer a dedicated online space for the club's loyal supporters.

> ### **Key Features**

The "Website PSB" is designed to be a comprehensive resource for the football club's community, featuring:

- **About Me/Club Section:** Provides an overview of the club's history, mission, and values, likely with team photos or a stadium view, creating a personal connection with fans.

- **Authentication (Login & Register):** Allows users to create accounts, enabling access to exclusive "Member Area" features.

- **League Standings (Klasemen Liga):** Displays up-to-date league tables, showing the team's position, points, and other relevant statistics.

- **Next Match Information:** Clearly presents details for upcoming matches, including date, time, opponent, and venue, helping fans plan their support.

- **News Section:** Publishes the latest club news, match reports, player updates, and general announcements, keeping fans informed and engaged.

- **Player List & Detail:** Showcases the full roster of players with individual profiles, including photos, positions, and possibly statistics or biographical information.

- **Member Area:** An exclusive section for registered members, potentially offering benefits like voting, merchandise discounts, transparent financial reports, and access to a club store. This suggests features like:

    - Digital Member Card

    - Access to Member Partner benefits

    - Discount on Official Merchandise

    - Voting Feature

    - Transparency in financial reports

    - Dedicated Store

    - Donation options

> ### **Tech Stack**

This project was built with a robust fullstack approach, leveraging popular technologies for both the frontend and backend:

- **Frontend:** React.js, Tailwind CSS

- **Backend:** Laravel

- **Database:** MySQL

> ### **My Role & Contribution**

As a **Fullstack Developer** on the "Website PSB" project, I was responsible for both the client-side and server-side development. My contributions included designing and implementing the user interface with React.js and Tailwind CSS, building the backend API with Laravel to manage data, and setting up the MySQL database to store all club-related information, including user data, match results, news, and player details. I handled the entire development lifecycle from database schema design to deploying the final user-facing features.

> ### **Lessons Learned & Growth**

Developing the "Website PSB" was an incredibly enriching experience that significantly broadened my skillset and understanding of fullstack development:

- **Integrated Fullstack Development:** I gained invaluable experience in seamlessly connecting frontend (React.js, Tailwind CSS) with backend (Laravel) and database (MySQL), understanding the full data flow and architectural considerations of a complete web application.

- **Backend API Development with Laravel:** I honed my skills in building robust and secure APIs, handling user authentication, data retrieval, and data manipulation, which are critical for dynamic websites.

- **Database Management & Optimization:** Working with MySQL for storing and managing diverse data like match results, news articles, and user profiles deepened my understanding of database design, queries, and performance considerations.

- **User Authentication & Security:** Implementing login and registration systems provided practical experience in handling user credentials securely and managing user sessions.

- **Real-world Application Development:** This project simulated a real-world scenario, requiring me to think about scalability, maintainability, and providing a comprehensive solution for a specific client need (the football club).

- **Dynamic Content Management:** I learned how to build a system that allows for easy updates of content, such as league standings, match schedules, and news articles, without requiring direct code changes.
